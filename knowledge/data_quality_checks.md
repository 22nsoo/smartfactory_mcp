# 센서 데이터 품질 확인

## sample_count 확인

1분 Window의 sample_count가 평소보다 낮으면 평균, 표준편차와 RMS가 충분한 관측치를 대표하지 못할 수 있다. 낮은 표본 Window의 이상 점수는 설비 이상보다 통신 지연, 수집 중단 또는 비가동 상태의 영향을 먼저 검토한다.

## 수집 공백 확인

직전 Window와의 gap_minutes가 크면 공백 직후 값이 모델에 낯선 패턴으로 보일 수 있다. 공백 전후의 생산 상태, 네트워크와 게이트웨이 로그, 센서 전원 상태를 함께 확인한다. 존재하지 않는 값을 임의 보간해 정상처럼 만들지 않는다.

## 센서 고정과 배선

가속도 센서의 체결 토크, 장착면, 방향 또는 케이블 고정이 바뀌면 실제 설비 상태가 같아도 측정 분포가 달라질 수 있다. 정비 작업이나 센서 교체 이후에는 기존 모델 기준을 그대로 적용할 수 있는지 재검증한다.

## 교차 검증

단일 센서만 급변하면 센서 자체 문제를 의심하고, 인접 센서나 온도·속도 값도 동시에 변하면 실제 공정 변화 가능성을 검토한다. 현재 공개 데이터에는 센서와 실제 설비 위치의 매핑이 없으므로 현장 판단에는 추가 메타데이터가 필요하다.
